About this database

Tools are grouped by discipline. The rotary equipment handbook holds the general reference, which spans every machine family, and the centrifugal pump knowledge base, which goes deep on one. Dedicated tools for compressors, turbines and fans follow.

Each tool is self-contained: it can be opened from this site, copied to a laptop, or carried on a USB stick and it will still work. Source files for every tool live alongside it in the repository, so anyone can correct or extend it — see the repository README for how to add a new tool.
