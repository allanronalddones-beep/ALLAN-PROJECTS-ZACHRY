## Chapter 1 — Units, Conversions & Formulas

**Units and constants**

- BIPM, *The International System of Units (SI)*, 9th edition, 2019. Defines the seven exact constants used in §1.1.
- CODATA internationally recommended values of the fundamental physical constants, 2018 adjustment.
- ISO 80000-1:2022, *Quantities and units — Part 1: General*.
- ISO 80000-4:2019, *Quantities and units — Part 4: Mechanics*.
- NIST Special Publication 811, *Guide for the Use of the International System of Units*.

**Reference conditions**

- ISO 13443:1996, *Natural gas — Standard reference conditions* (15 °C, 101.325 kPa).
- ISO 5024:1999, *Petroleum liquids and gases — Measurement — Standard reference conditions*.

**Viscosity**

- ASTM D2161, *Standard Practice for Conversion of Kinematic Viscosity to Saybolt Universal Viscosity or to Saybolt Furol Viscosity*.
- ASTM D445, *Standard Test Method for Kinematic Viscosity of Transparent and Opaque Liquids*.
- ISO 3448:1992, *Industrial liquid lubricants — ISO viscosity classification* (the ISO VG grades in Table 1.3-1).

**Petroleum density**

- ASTM D1250 / API MPMS Chapter 11, *Petroleum Measurement Tables*.
- ASTM D287, *Standard Test Method for API Gravity of Crude Petroleum and Petroleum Products*.

**Pumps and hydraulics**

- API Standard 610 / ISO 13709, *Centrifugal Pumps for Petroleum, Petrochemical and Natural Gas Industries*. NPSH margin requirements, §1.3.6.
- ANSI/HI 9.6.7, *Effects of Liquid Viscosity on Rotodynamic Pump Performance* (Hydraulic Institute).
- ANSI/HI 9.6.1, *Rotodynamic Pumps — Guideline for NPSH Margin*.

## A note on citation practice

Each chapter ends with its own **Sources** section listing only what that chapter actually drew on, with clause numbers where a specific requirement is referenced.

Standards evolve. Edition numbers are given where a value is edition-dependent. Where none is given, the current edition at the time of writing applies and the governing edition for any project is the one named in the project specification — not the one cited here.
