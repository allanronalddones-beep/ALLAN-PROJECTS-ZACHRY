2.1How the families fit together

Five bodies produce almost everything that governs a rotating equipment package. They overlap, and knowing which one leads in a given area saves a great deal of argument.

Table 2.1-1 — Standards bodies and their territory
BodyTerritoryCharacter
API
American Petroleum Institute		Machine-level requirements for oil, gas and petrochemical service — pumps, compressors, turbines, gears, couplings, lube systemsPurchaser-oriented. Written as requirements on a vendor, with datasheets and a bullet list of decisions the purchaser must make.
ISOInternational equivalents of many API standards, plus vibration, balancing and reference conditionsOften a direct adoption of the API text under a dual number.
ASMEPressure boundary, flanges, bolting, materials, performance test codesGoverns the pressure-containing parts that API standards then reference.
IECElectrical machines, hazardous area equipment, ingress protection — international practiceZone-based hazardous area philosophy.
NEMA / NFPAElectrical machines and hazardous area — North American practiceDivision-based hazardous area philosophy. NFPA 70 (NEC) is law in the US.
The usual hierarchy on a project. Project specification → client's own engineering standard → the API/ISO standard it invokes → the ASME/IEC standards that one references. Each layer may add requirements but should not relax the one below it. Where a project specification is silent, the API standard governs; where it conflicts, the project specification normally wins — but conflicts are worth raising rather than silently resolving.

2.3ISO equivalents and dual numbering

Several API standards are adopted verbatim by ISO under a second number. API 610 and ISO 13709 are the same document; a vendor offering “ISO 13709 compliance” is offering API 610 compliance.

Editions diverge even when text does not. The ISO adoption usually lags the API edition. API 610 12th edition and ISO 13709 2nd edition are not automatically the same revision. If an edition matters — and for pump nozzle loads and NPSH margin it does — cite the API number and edition explicitly on the requisition.

Philippines supply. The Philippines distributes at 60 Hz, 230 V single phase and 230 / 400 / 480 V three phase, which places it with North American frequency practice while much installed plant equipment is IEC-framed. Expect mixed IEC-frame, 60 Hz motors. A 50 Hz IEC motor run at 60 Hz turns 20 % faster and, on a centrifugal load, absorbs roughly 1.73 times the power — see the affinity laws in §4.3.

MR0175 and MR0103 are not interchangeable. MR0175/ISO 15156 governs upstream production environments. MR0103 governs refining environments. They set different limits and a material qualified to one is not automatically acceptable under the other. Chapter 3 §3.5 covers sour service selection.

2.8Reading a citation

A complete citation carries four pieces of information. Datasheets routinely omit two of them and create ambiguity:

ElementExampleWhy it matters
Body and numberAPI 610Identifies the document
Edition12th editionRequirements change between editions — nozzle load tables and NPSH margin have both moved
Year2021Disambiguates where edition numbering is unclear
Clause§6.1.2Points at the actual requirement instead of the whole document

Written in full: API Standard 610, 12th edition (2021), §6.1.2.

Bullets and decisions. API machine standards mark purchaser decisions with a bullet (●) in the margin. Every bulleted item is something the purchaser must specify; leaving it blank means the vendor decides, and the vendor will decide in its own favour. Working through the bullet list is the single most valuable hour spent on an API requisition.
